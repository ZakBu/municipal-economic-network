# Карта рабочего пространства

Это навигация по совместной работе; исследовательская методология ещё не определена.

```text
Контекст задачи (docs/PROJECT.md)
  → согласование объёма с BMAD (_bmad-output/)

  → ветки с кодом, конфигами и тестами
  → Pull Request и ревью
  → принятые решения (docs/decisions/)
  → проверенные результаты и материалы защиты (docs/, reports/)
```
