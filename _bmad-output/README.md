# Рабочие документы BMAD

planning-artifacts/ — согласованный контекст и планы;
implementation-artifacts/ — спецификации, истории и материалы выполнения.
Другие каталоги могут создаваться конкретным workflow.

Текстовые документы коммитятся вместе с задачей; временные runtime-кеши — нет.
Связывайте документы с Issue. Новые планы ещё не созданы и не считаются утверждёнными.
