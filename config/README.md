# Конфигурации

base.yaml содержит только имя проекта и пути.
features.yaml, graph.yaml, clustering.yaml, visualization.yaml — пустые словари для будущих задач.
Они не задают алгоритмы или методологию и пока не используются вычислительным pipeline.
Добавляя параметры, документируйте значения и включайте проверку в соответствующий модуль.
