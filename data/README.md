# Данные

`raw/` — исходные файлы; `interim/` — промежуточные; `processed/` — готовые к использованию.
Все три каталога исключены из Git. Большие файлы храните в согласованном общем хранилище.
Исходные данные пока не подключены. Источники и способы получения определяет команда.

Для каждого набора добавьте в docs/DATA.md: название, источник, ссылку, дату получения,
период, географию, единицы, ограничения использования, размер, SHA256 и ответственного.
Не сохраняйте секретные ссылки, пароли и персональные данные в документации.
Небольшие синтетические примеры для тестов можно хранить в tests/fixtures/.
