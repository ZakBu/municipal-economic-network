# Контекст проекта

## Цель

Команда исследует экономическую структуру российских муниципалитетов с помощью
кластеризации динамических атрибутированных сетей. Нужно организовать общую разработку,
сохранять решения и воспроизводимо собирать результат хакатона.

## Исходные требования задачи

- Узел — муниципальное образование, атрибуты — его экономические характеристики.
- Рёбра отражают экономическую близость; сеть рассматривается во времени.
- Требуются группировка МО, анализ изменений групп и содержательная визуализация.
- По постановке обязателен минимум один датасет СберИндекса; возможны данные Росстата.
- На выходе нужны код, конфигурации, инструкция запуска, краткий русский отчёт и презентация/лендинг.

Источники, признаки, формулы, алгоритмы, метрики и временная модель здесь не выбраны.
Команда определит их в отдельных задачах. Сейчас реальные данные не загружены.

## Организация

Владелец репозитория — ZakBu. Состав команды и роли заполняются в GitHub Issues/Project;
имена участников и сроки не предполагаются автоматически.
GitHub хранит код и общие документы, BMAD помогает превращать согласованные задачи в изменения.
Telegram используется для быстрых обсуждений; итог обсуждения переносится в Issue или ADR.

## Первые действия команды

1. Подключить участников и договориться о ролях.
2. Уточнить срок, формат сдачи и требования организаторов.
3. Получить данные и описать способ доступа.
4. Согласовать краткую спецификацию первой рабочей версии с BMAD.
5. Разбить работу на небольшие задачи и назначить ответственных.
